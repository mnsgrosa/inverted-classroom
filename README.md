# Inverted Classroom

Este repositório contém uma skill para planejar e conduzir estudos de forma ativa.

## Skills

### `inverted-classroom`

Local: `.agents/skills/inverted-classroom/SKILL.md`

É uma abordagem de estudo liderada pelo aluno: primeiro você tenta recuperar o que sabe e praticar; depois, o tutor identifica lacunas e oferece perguntas, dicas e explicações direcionadas. O percurso se adapta ao seu objetivo, conhecimento prévio, tempo e profundidade desejada.

## Como usar

Peça ao assistente para criar ou conduzir um curso sobre o tema desejado. Informe seu objetivo, o que já sabe, o tempo disponível, a profundidade desejada e a pasta onde os materiais podem ser criados. A skill confirma essas informações antes de montar o curso.

Durante o curso, tente responder e resolver os exercícios antes de consultar explicações. O tutor acompanha seu raciocínio, registra dúvidas e ajusta as próximas atividades. Consulte `.agents/skills/inverted-classroom/SKILL.md` para as instruções completas.
